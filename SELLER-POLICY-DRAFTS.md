# Seller decisions — not final buyer terms

These are planning prompts for the product owner, not a published license, legal advice or promises to buyers. Fill them in and approve your final terms before listing the product. Existing third-party software licenses still apply; see THIRD-PARTY-NOTICES.md.

| Decision | Fill in before launch |
|---|---|
| Product model | Self-hosted source package, assisted setup, or managed single-owner hosting |
| Buyer usage license | Allowed businesses/deployments, client work, modification and redistribution rules |
| Included services | Whether setup, platform permissions, migrations and recovery help are included |
| Support | Real contact address, supported channels, working hours, response target and duration |
| Updates | Delivery method, included update period, migration support and beta-framework policy |
| Hosting | Who owns/pays for Cloudflare, who holds credentials, how recurring costs are communicated |
| Refunds/cancellations | Seller's approved policy and relevant sales-platform requirements |
| Data | Buyer ownership, backup responsibilities, retention, access and deletion process |
| API integrations | Which real integrations passed acceptance testing; approvals and token renewals required |
| Accessibility | Verified browser/mobile/keyboard coverage and known limitations |

Listing checklist: use actual dashboard screenshots, show a sample-only demo, disclose required hosting/setup, list exactly what is included, and state the backup/import limits. Do not promise instant metrics from every platform, offline operation, multi-client permissions, automated payment processing or guaranteed tax compliance.

Suggested factual product description for editing: “A customizable, self-hosted dashboard for one small-business owner to organize clients, projects, content, invoices and resources. Includes ten themes, monthly planning imports, reviewed post-analytics CSV imports and full workspace backups. Cloudflare setup and a private owner login are required. Optional supported API integrations require separate platform authorization.”
